Each card below is the same landing page rendered in a different visual theme, so you're comparing styling, not content. Scroll, compare, and tell me which one to build — or mix (e.g. one theme's type with another's layout).

Note: artifacts can't load webfonts, so each theme uses a system-font stand-in. The real font each theme ships with is named next to its title.
